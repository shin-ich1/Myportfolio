LΛN Portfolio · Google Drive Integration

Privacy Policy

This policy explains how LAN Portfolio Storage, the administrator-managed Google Drive integration for LΛN Portfolio, accesses, uses, stores, and shares Google user data.

Last updated: October 30, 2026

1. What the integration does

LAN Portfolio Storage allows the authorized portfolio administrator to connect a Google Drive account to organize and manage media for the LΛN Portfolio website. It supports creating managed folders, uploading portfolio images, videos, documents, and other files, checking storage readiness, and delivering media selected for public display.

The Google Drive connection is for the portfolio administrator's storage management; public visitors do not need to sign in to Google Drive to view the portfolio.

2. Google user data we access

The integration requests the Google Drive file-specific OAuth permission https://www.googleapis.com/auth/drive.file. This permits management of files created by, or explicitly opened for use with, this application; it does not request access to all unrelated files in your Google Drive.

When authorized, the integration may process the connected account's display name and email address, available storage quota, and information about managed files and folders, such as IDs, filenames, file types, sizes, locations, access permissions, and relevant metadata.

Google OAuth access tokens and refresh tokens are used to authenticate permitted operations. The integration does not request or store your Google account password.

3. How we use the data

Google user data is used only to connect and verify the selected storage account; create and organize application-managed folders; upload, retrieve, and manage portfolio assets; check storage information; and serve assets the administrator has designated for public portfolio display.

The integration does not use Google Drive data to target advertisements or sell Google user data. It does not access Gmail or Google Contacts as part of this storage functionality.

4. Where data is stored and processed

Media files are stored in the connected Google Drive account. A server-side Cloudflare Worker performs the Google OAuth exchange, holds the connection's access tokens and refresh tokens in application-side Cloudflare storage, and handles authorized storage requests. OAuth credentials are not intentionally exposed in the public portfolio page.

Firebase Firestore stores the portfolio's storage-profile settings, file references, and related content metadata. Google and these infrastructure services process information needed to provide the requested storage functionality.

5. Public sharing of portfolio media

The administrator may designate selected managed media as public portfolio assets and set the relevant Drive folder to a public viewer permission. In that case, those files or their delivery URLs may be publicly accessible to people visiting the portfolio. Do not upload sensitive or confidential material to folders intended for public display.

Unrelated Google Drive files are not made public by this integration. Application-side OAuth credentials are not published alongside public portfolio media.

6. Retention, revocation, and deletion

Storage profile information and references are retained while needed to manage the portfolio and its linked assets. The administrator can manage or delete portfolio files and references using the applicable management tools.

The administrator can disconnect or remove a Google Drive storage profile from the Admin interface after clearing its dependent references and default assignments. Removing the connection deletes the integration's stored OAuth connection for that profile, but does not automatically delete existing Google Drive files. Those files must be deleted separately if desired.

You may also revoke the application's access through your Google Account's third-party connections settings. For questions about access or to request deletion of data associated with this integration, contact the address below; identity and ownership may need to be verified before account-level changes.

7. Contact and policy changes

For privacy questions or requests related to LAN Portfolio Storage, email lagmayr2@gmail.com.

This policy covers the Google Drive storage integration, not all features of the public portfolio. The policy may be updated to reflect changes to storage functionality or data-handling practices. The latest version will be available on this page.
